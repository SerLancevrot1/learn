# Терминал с нуля: Linux и PowerShell

[Все конспекты](../README.md) · [Рабочие заметки](README.md) · [Git с нуля](git.md)

Этот гайд рассчитан на первый опыт. Сначала прочитай разделы 1–4, затем выполни практику в разделе 12. Остальные разделы используй как справочник. Примеры из разных разделов независимы: не нужно выполнять весь файл подряд.

## 1. Что такое терминал и куда вводить команды

**Терминал** — окно, в котором ты вводишь команды и читаешь ответы. **Оболочка** — программа, которая понимает эти команды. В этом гайде рассматриваются Bash в Linux и PowerShell в Windows. В Linux бывают и другие оболочки, а PowerShell можно установить и в Linux.

В Windows открой меню «Пуск», найди **PowerShell** и запусти его. Windows Terminal — приложение, внутри которого тоже можно открыть вкладку PowerShell. В IntelliJ IDEA есть встроенный терминал: **View → Tool Windows → Terminal**. Он выполняет команды через выбранную в настройках оболочку.

Приглашение обычно выглядит так:

```text
PS C:\Users\limon\IdeaProjects\learn>     ← PowerShell
user@computer:~/projects/learn$          ← Bash в Linux
```

Это примеры того, что уже напечатала оболочка. Вводи только команду после `>` или `$`, сами приглашения копировать не нужно. Нажми **Enter**, чтобы выполнить команду. Дождись следующего приглашения перед вводом новой команды. Если команда ничего не напечатала, она могла успешно выполниться.

Терминал PowerShell не становится Linux после ввода Linux-команды. Для Linux нужна Linux-среда: например, отдельный компьютер, виртуальная машина или настроенный WSL. Команды из блоков `bash` выполняй там; команды из блоков `powershell` — в PowerShell.

## 2. Как устроена команда

Обычно команда состоит из имени, параметров и значений:

```bash
ls -l /tmp
```

Здесь `ls` показывает содержимое папки, `-l` включает подробный вид, `/tmp` указывает папку. Параметры меняют поведение команды, а пути и другие значения задают, с чем работать.

```powershell
Get-ChildItem -Path "C:\Users"
```

Здесь `Get-ChildItem` показывает содержимое папки, `-Path` — имя параметра, `"C:\Users"` — его значение. Многие команды PowerShell устроены как **Глагол-Существительное**: `Get-Content` читает содержимое, `Copy-Item` копирует объект.

В PowerShell есть короткие псевдонимы: например, `ls` обычно означает `Get-ChildItem`, а `cat` — `Get-Content`. Это не Linux-программы: их параметры отличаются. В гайде используются полные имена, чтобы различия были видны.

Если путь содержит пробелы, заключай его в кавычки:

```bash
cd "$HOME/My Projects"
```

```powershell
Set-Location "$HOME\My Projects"
```

`$HOME` — домашняя папка текущего пользователя. Кавычки объединяют путь с пробелами в одно значение. Примеры с такими папками сработают, только если папки существуют.

## 3. Текущая папка и пути

У терминала всегда есть **текущая папка**. Команда с относительным путём ищет файл именно от неё. Если файл «не найден», сначала проверь, где находишься.

| Обозначение | Значение | Пример |
| --- | --- | --- |
| `.` | Текущая папка | `./notes.txt` в Bash, `.\notes.txt` в PowerShell |
| `..` | Родительская папка, на уровень выше | `cd ..` |
| `~` | Домашняя папка | `cd ~` |
| Абсолютный путь | Полный путь от корня или диска | `/home/user/learn`, `C:\Users\limon\IdeaProjects\learn` |
| Относительный путь | Путь от текущей папки | `docs/theory`, `docs\theory` |

В Linux разделитель папок — `/`, а корень файловой системы — `/`. В Windows привычный разделитель — `\`, а диски имеют имена вроде `C:`. В Linux регистр имён имеет значение: `File.txt` и `file.txt` обычно разные файлы. В Windows регистр обычно не различается.

| Задача | Linux / Bash | PowerShell |
| --- | --- | --- |
| Узнать текущую папку | `pwd` | `Get-Location` |
| Показать её содержимое | `ls` | `Get-ChildItem` |
| Показать скрытые элементы | `ls -a` | `Get-ChildItem -Force` |
| Подробный список | `ls -lh` | `Get-ChildItem` |
| Перейти в папку `docs` | `cd docs` | `Set-Location docs` |
| Подняться на уровень выше | `cd ..` | `Set-Location ..` |
| Перейти домой | `cd ~` | `Set-Location ~` |

`cd` работает и в PowerShell как псевдоним `Set-Location`. Переход в папку не перемещает файлы, а только меняет точку, от которой выполняются следующие команды.

## 4. Клавиши, которые стоит выучить первыми

| Клавиша | Что делает |
| --- | --- |
| **Tab** | Дополняет имя команды или путь; поведение зависит от оболочки |
| **↑ / ↓** | Показывает предыдущие и следующие команды из истории |
| **Ctrl+C** | Обычно прерывает выполняющуюся команду; в некоторых терминалах при выделенном тексте копирует его |
| **Ctrl+L** | В типичных настройках Bash и PowerShell очищает видимую область терминала |
| **Enter** | Выполняет введённую команду |

Также можно очистить экран командой `clear` в Bash или `Clear-Host` в PowerShell. Это не удаляет файлы. `exit` завершает текущую оболочку; в SSH-сеансе возвращает на твой компьютер.

Если вместо обычного приглашения появился `>` в Bash или `>>` в PowerShell, возможно, ты не закрыл кавычку или скобку. Нажми **Ctrl+C** и введи команду заново. При запросе пароля в Linux символы обычно вообще не отображаются: это нормально.

## 5. Создание, копирование, перемещение и удаление

Следующие команды меняют файлы. Имена в таблице — учебные примеры: исходный файл `notes.txt` должен существовать, а папка `backup` должна быть создана. Сначала проверь текущую папку и её содержимое.

| Задача | Linux / Bash | PowerShell |
| --- | --- | --- |
| Создать папку | `mkdir terminal-practice` | `New-Item -ItemType Directory -Path terminal-practice` |
| Создать пустой файл | `touch notes.txt` | `New-Item -ItemType File -Path notes.txt` |
| Скопировать файл под новым именем | `cp -i notes.txt notes-copy.txt` | `Copy-Item -LiteralPath notes.txt -Destination notes-copy.txt -Confirm` |
| Скопировать файл в папку | `cp -i notes.txt backup/` | `Copy-Item -LiteralPath notes.txt -Destination .\backup\ -Confirm` |
| Скопировать папку со всем содержимым | `cp -ri backup backup-copy` | `Copy-Item -LiteralPath backup -Destination backup-copy -Recurse -Confirm` |
| Переименовать файл | `mv -i notes-copy.txt draft.txt` | `Rename-Item -LiteralPath notes-copy.txt -NewName draft.txt` |
| Переместить файл в папку | `mv -i draft.txt backup/` | `Move-Item -LiteralPath draft.txt -Destination .\backup\ -Confirm` |
| Удалить файл с подтверждением | `rm -i notes-copy.txt` | `Remove-Item -LiteralPath notes-copy.txt -Confirm` |
| Удалить пустую папку | `rmdir empty-folder` | `Remove-Item -LiteralPath empty-folder -Confirm` |

В `cp`, `mv` и `rm` параметр `-i` запрашивает подтверждение перед перезаписью или удалением. В PowerShell `-Confirm` запрашивает подтверждение действия. `-LiteralPath` воспринимает путь буквально: например, квадратные скобки в имени не становятся шаблоном поиска.

`touch` создаёт файл, если его нет, а для существующего обновляет время изменения. Копирование папок может давать разную вложенность в зависимости от того, существует ли папка назначения: после операции проверь результат через `ls` или `Get-ChildItem`.

### Удаление папки с содержимым

Удалённое из терминала обычно не попадает в корзину. Отдельно проверь путь перед удалением. Не тренируйся на папках проекта, системных папках и единственных копиях файлов.

В Linux сначала посмотри, что находится внутри учебной папки, затем удали её с вопросами о подтверждении:

```bash
pwd
ls -la ./terminal-practice
rm -ri ./terminal-practice
```

В PowerShell сначала посмотри содержимое, затем сделай предварительный просмотр через `-WhatIf`:

```powershell
Get-Location
Get-ChildItem -LiteralPath .\terminal-practice -Recurse
Remove-Item -LiteralPath .\terminal-practice -Recurse -WhatIf
```

`-WhatIf` показывает предполагаемое действие без выполнения. После проверки для настоящего удаления замени `-WhatIf` на `-Confirm`. Не все команды поддерживают `-WhatIf`; поддержка есть у приведённого `Remove-Item`.

## 6. Чтение и запись текстовых файлов

| Задача | Linux / Bash | PowerShell |
| --- | --- | --- |
| Прочитать небольшой файл | `cat notes.txt` | `Get-Content -LiteralPath notes.txt` |
| Читать большой файл по страницам | `less app.log` | `Get-Content -LiteralPath app.log -TotalCount 100` — прочитать первые 100 строк |
| Первые 10 строк | `head -n 10 app.log` | `Get-Content -LiteralPath app.log -TotalCount 10` |
| Последние 20 строк | `tail -n 20 app.log` | `Get-Content -LiteralPath app.log -Tail 20` |
| Следить за новыми строками лога | `tail -f app.log` | `Get-Content -LiteralPath app.log -Tail 20 -Wait` |
| Записать текст, заменив содержимое | `printf '%s\n' 'Hello' > notes.txt` | `Set-Content -LiteralPath notes.txt -Value 'Hello' -Encoding UTF8` |
| Дописать строку в конец | `printf '%s\n' 'Another line' >> notes.txt` | `Add-Content -LiteralPath notes.txt -Value 'Another line' -Encoding UTF8` |

В `less` листай стрелками или пробелом, нажми `q` для выхода. Наблюдение за логом через `tail -f` или `-Wait` продолжается до **Ctrl+C**.

В Bash `>` записывает вывод команды в файл и **стирает прежнее содержимое**. `>>` добавляет в конец. В PowerShell эти операторы тоже есть, но для текста в примерах используются явные команды с кодировкой. Windows PowerShell 5.1 и PowerShell 7 имеют разные настройки кодировок по умолчанию; явный `-Encoding UTF8` помогает при работе с русским текстом. В 5.1 он создаёт UTF-8 с BOM, в 7 — без BOM.

## 7. Поиск файлов и текста

### Linux / Bash

```bash
# Найти файлы с расширением .java в текущей папке и вложенных папках
find . -type f -name '*.java'

# Найти строки с ERROR в одном файле, показав номера строк
grep -n 'ERROR' app.log

# Найти текст в папке src и вложенных папках
grep -rnF 'OrderService' src/

# Искать без учёта регистра
grep -ni 'error' app.log
```

`-r` означает обход вложенных папок, `-n` — номера строк, `-i` — игнорирование регистра, `-F` — поиск буквального текста вместо регулярного выражения. Маску `'*.java'` заключают в кавычки, чтобы её обрабатывал `find`.

### PowerShell

```powershell
# Найти файлы .java в текущей папке и вложенных папках
Get-ChildItem -Path . -Recurse -File -Filter *.java

# Найти строки с ERROR в одном файле
Select-String -LiteralPath app.log -Pattern 'ERROR' -SimpleMatch

# Найти текст во всех Java-файлах папки src
Get-ChildItem -Path .\src -Recurse -File -Filter *.java |
    Select-String -Pattern 'OrderService' -SimpleMatch
```

`Select-String` обычно выводит имя файла, номер строки и найденную строку. По умолчанию он не различает регистр; для различения добавь `-CaseSensitive`. Параметр `-SimpleMatch` включает поиск буквального текста.

Символ `|` передаёт результат одной команды следующей. Bash обычно передаёт текст, PowerShell между своими командами передаёт объекты с полями: именем, размером и другими свойствами. Поэтому похожие задачи могут записываться по-разному.

Например, вывести пять самых больших файлов текущей папки в PowerShell:

```powershell
Get-ChildItem -File |
    Sort-Object Length -Descending |
    Select-Object -First 5 Name, Length
```

Здесь команды последовательно получают файлы, сортируют по размеру и оставляют первые пять с именем и размером в байтах.

## 8. Запуск программ и переменные окружения

Внешняя программа запускается по имени, если установлена и доступна через **PATH** — список папок, где оболочка ищет исполняемые файлы:

```text
java -version
git --version
mvn -version
```

Эти команды можно использовать в обеих оболочках. Если видишь `command not found` или «имя не распознано», проверь установку, имя команды и PATH. После установки иногда нужно открыть новый терминал.

| Задача | Linux / Bash | PowerShell |
| --- | --- | --- |
| Найти, что запускается по имени `java` | `command -v java` | `Get-Command java` |
| Показать PATH | `printenv PATH` | `$env:PATH` |
| Показать JAVA_HOME | `printenv JAVA_HOME` | `$env:JAVA_HOME` |
| Задать переменную окружения для текущего сеанса и дочерних программ | `export APP_ENV=local` | `$env:APP_ENV = 'local'` |
| Прочитать эту переменную | `printenv APP_ENV` | `$env:APP_ENV` |

Изменения переменных в этих примерах не сохраняются для будущих сеансов терминала. Уже запущенные отдельно приложения также не получат их автоматически.

Для запуска файла из текущей папки путь указывают явно. Например, если в проекте есть Maven Wrapper:

```bash
./mvnw test
```

```powershell
.\mvnw.cmd test
```

Эти команды запускают тесты проекта. В Linux скрипту может понадобиться право выполнения: `chmod u+x ./mvnw` добавляет это право владельцу. Используй его только для известного тебе файла. Не ослабляй глобальные настройки безопасности PowerShell ради незнакомого скрипта.

В PowerShell для запуска программы по пути с пробелами нужен оператор `&`:

```powershell
& "C:\Program Files\Java\jdk-17\bin\java.exe" -version
```

Это пример пути: замени его на путь к своей установленной Java. Без `&` путь в кавычках воспринимается как строка.

## 9. Процессы, место на диске и сеть

**Процесс** — запущенная программа или её часть. **PID** — числовой идентификатор процесса.

| Задача | Linux / Bash | PowerShell в Windows |
| --- | --- | --- |
| Показать процессы | `ps aux` | `Get-Process` |
| Найти процесс по имени | `pgrep -a java` | `Get-Process -Name java` |
| Смотреть загрузку системы | `top` (`q` — выход) | Открыть диспетчер задач: `taskmgr` |
| Посмотреть свободное место | `df -h` | `Get-PSDrive -PSProvider FileSystem` |
| Оценить размер папки | `du -sh ./docs` | `Get-ChildItem .\docs -Recurse -File \| Measure-Object -Property Length -Sum` — сумма размеров файлов в байтах |
| Проверить ответ узла | `ping -c 4 example.com` | `Test-Connection example.com -Count 4` |
| Проверить TCP-порт | `ss -ltn` — локальные слушающие TCP-порты | `Test-NetConnection localhost -Port 8080` — доступность порта 8080 |

В строке размера папки символ `|` — обычный конвейер; таблица экранирует его только для отображения Markdown. Проверка `ping` использует ICMP: отсутствие ответа не доказывает, что сайт не работает. `ss` входит в набор iproute2 и может отсутствовать в минимальной Linux-среде. Команды `Test-NetConnection` и `taskmgr` в таблице относятся к Windows.

Завершать процесс стоит только после проверки его имени и PID: это может прервать запись данных. Сначала попробуй **Ctrl+C** в терминале, где ты его запустил. В Bash `kill 12345` отправляет процессу с PID `12345` запрос завершения. В PowerShell `Stop-Process -Id 12345 -Confirm` завершает процесс после подтверждения; это не гарантирует корректного сохранения его данных. `12345` здесь — пример, его нельзя копировать без проверки.

### HTTP-запрос

```bash
# Показать заголовки HTTP-ответа
curl -I https://example.com
```

```powershell
# Получить HTTP-ответ и показать код состояния
(Invoke-WebRequest -Uri 'https://example.com' -Method Head -UseBasicParsing).StatusCode
```

В Windows PowerShell 5.1 имя `curl` может быть псевдонимом `Invoke-WebRequest`. Чтобы вызвать установленный настоящий curl в Windows, используй `curl.exe`. Не рассчитывай, что параметры `curl -I` одинаково работают у программы и псевдонима.

## 10. Права доступа, sudo и SSH

В Linux `ls -l` показывает права вроде `-rw-r--r--`. Они описывают чтение (`r`), запись (`w`) и выполнение (`x`) для владельца, группы и остальных. Для папок право `x` позволяет проходить внутрь.

`sudo` запускает конкретную команду с правами другого пользователя, обычно администратора. Оно может запросить пароль твоей учётной записи и работает только при выданных правах. Не добавляй `sudo` автоматически при любой ошибке: сначала прочитай сообщение и проверь путь. В Windows повышение прав обычно делается запуском PowerShell «от имени администратора». Для учебной практики ниже это не требуется.

SSH позволяет открыть терминал на другом компьютере:

```text
ssh username@server-address
```

Здесь `username` и `server-address` нужно заменить реальными данными. Команда доступна в Linux и в Windows с установленным клиентом OpenSSH. При первом подключении проверь отпечаток ключа сервера по доверенному источнику, прежде чем соглашаться. После входа команды выполняются **на сервере**, а не на твоём компьютере. `exit` завершает подключение.

## 11. Помощь и частые ошибки

| Ситуация | Что проверить |
| --- | --- |
| «Файл или папка не найдены» | Текущую папку, точное имя, регистр в Linux и кавычки вокруг пути с пробелами |
| «Команда не найдена» | Правильную оболочку, установку программы и PATH |
| «Отказано в доступе» | Путь, права и не занят ли файл другой программой |
| Команда долго не завершается | Возможно, это наблюдение за логом, сервер или ожидание ввода; для остановки обычно подходит Ctrl+C |
| После копирования команда ведёт себя странно | Не попали ли в неё приглашение, типографские кавычки `“ ”` или длинное тире вместо `-` |
| PowerShell не принимает `&&` | В Windows PowerShell 5.1 этот оператор не поддерживается; вводи команды отдельными строками |

Помощь в Linux:

```bash
ls --help
man ls
help cd
```

`--help` поддерживается многими внешними программами, но не всеми. `man` открывает руководство, если оно установлено; выход — `q`. `help cd` показывает справку по встроенной команде Bash.

Помощь в PowerShell:

```powershell
Get-Help Get-ChildItem -Examples
Get-Help Remove-Item -Full
Get-Command *Content*
$PSVersionTable.PSVersion
```

Первые две команды показывают примеры и справку, третья ищет команды с `Content` в имени, четвёртая показывает версию PowerShell. Полнота локальной справки зависит от того, установлены ли файлы помощи.

## 12. Практика на 15 минут

Выбери **один** блок для своей оболочки. Практика создаёт папку `terminal-practice` внутри домашней папки. Если такая папка уже существует, выбери новое имя и замени его в командах. Выполняй по одной строке, проверяя результат. Если команда завершилась ошибкой, сначала разберись с ней.

### Linux / Bash

```bash
# 1. Перейти домой и проверить текущее место
cd ~
pwd

# 2. Создать учебную папку и перейти в неё
mkdir terminal-practice
cd terminal-practice

# 3. Создать файл из двух строк
printf '%s\n' 'Hello terminal' > notes.txt
printf '%s\n' 'ERROR: training example' >> notes.txt

# 4. Посмотреть список файлов и содержимое файла
ls -l
cat notes.txt

# 5. Сделать копию, затем переименовать её
cp -i notes.txt notes-copy.txt
mv -i notes-copy.txt draft.txt

# 6. Найти строку с ERROR
grep -n 'ERROR' notes.txt

# 7. Создать папку и переместить в неё копию
mkdir backup
mv -i draft.txt backup/
ls -l backup/

# 8. Удалить только копию; на вопрос ответить y, если путь верен
rm -i backup/draft.txt
rmdir backup

# 9. Убедиться, что исходный файл остался
cat notes.txt
pwd
```

### PowerShell

```powershell
# 1. Перейти домой и проверить текущее место
Set-Location ~
Get-Location

# 2. Создать учебную папку и перейти в неё
New-Item -ItemType Directory -Path terminal-practice
Set-Location terminal-practice

# 3. Создать файл из двух строк
Set-Content -LiteralPath notes.txt -Value 'Hello terminal' -Encoding UTF8
Add-Content -LiteralPath notes.txt -Value 'ERROR: training example' -Encoding UTF8

# 4. Посмотреть список файлов и содержимое файла
Get-ChildItem
Get-Content -LiteralPath notes.txt

# 5. Сделать копию, затем переименовать её
Copy-Item -LiteralPath notes.txt -Destination notes-copy.txt
Rename-Item -LiteralPath notes-copy.txt -NewName draft.txt

# 6. Найти строку с ERROR
Select-String -LiteralPath notes.txt -Pattern 'ERROR' -SimpleMatch

# 7. Создать папку и переместить в неё копию
New-Item -ItemType Directory -Path backup
Move-Item -LiteralPath draft.txt -Destination .\backup\
Get-ChildItem -LiteralPath backup

# 8. Посмотреть план удаления, затем удалить копию с подтверждением
Remove-Item -LiteralPath .\backup\draft.txt -WhatIf
Remove-Item -LiteralPath .\backup\draft.txt -Confirm
Remove-Item -LiteralPath .\backup -Confirm

# 9. Убедиться, что исходный файл остался
Get-Content -LiteralPath notes.txt
Get-Location
```

При запросе подтверждения в PowerShell прочитай варианты ответа и выбери подтверждение одной операции. Если отменить удаление файла, папка `backup` останется непустой: не подтверждай её рекурсивное удаление случайно.

Ожидаемый результат обеих практик: ты находишься в домашней папке внутри `terminal-practice`, в ней остался `notes.txt` с двумя строками; копия и `backup` удалены. Поиск показал `ERROR` на второй строке. Учебная папка с исходным файлом остаётся для повторения.

## 13. Шпаргалка: что запомнить сначала

| Действие | Linux / Bash | PowerShell |
| --- | --- | --- |
| Где я? | `pwd` | `Get-Location` |
| Что здесь лежит? | `ls` | `Get-ChildItem` |
| Перейти в папку | `cd folder` | `Set-Location folder` |
| На уровень выше | `cd ..` | `Set-Location ..` |
| Прочитать файл | `cat file.txt` | `Get-Content file.txt` |
| Найти текст | `grep -nF 'text' file.txt` | `Select-String -Path file.txt -Pattern 'text' -SimpleMatch` |
| Создать папку | `mkdir folder` | `New-Item -ItemType Directory -Path folder` |
| Остановить команду | Ctrl+C | Ctrl+C |
| Открыть помощь | `man имя-команды` | `Get-Help Имя-Команды -Examples` |

Для самопроверки без подсказки перейди в учебную папку, покажи её содержимое, прочитай файл, сделай копию и найди строку по слову. Затем объясни, чем отличаются текущая папка и полный путь, копирование и перемещение, перезапись и добавление в файл.
